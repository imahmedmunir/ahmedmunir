# Cybersecurity Portfolio

Professional portfolio website showcasing cybersecurity projects, skills, and experience.

## About This Portfolio

This is a minimal, professional portfolio designed for cybersecurity analyst roles. The site emphasizes hands-on lab work, particularly Active Directory security monitoring and detection engineering.

## Structure

- **index.html** - Main portfolio page with all sections
- **styles.css** - Clean, minimal styling with dark theme
- **script.js** - Smooth scrolling and subtle animations

## Deployment

This portfolio is designed for GitHub Pages:

1. Create a new repository named `yourusername.github.io`
2. Upload these files to the repository
3. Enable GitHub Pages in repository settings
4. Your site will be live at `https://yourusername.github.io`

## Customization Guide

### Update Your Information

1. **Personal Details** (index.html):
   - Replace "Your Name" with your actual name
   - Update email, LinkedIn, and GitHub links
   - Add your actual dates and company names in the Experience section

2. **Projects** (index.html):
   - Update GitHub repository links
   - Add documentation links if available
   - Customize project descriptions based on your actual work

3. **Colors** (styles.css):
   - Modify CSS variables in `:root` to change color scheme
   - Current theme: Professional dark blue
   - Alternative: Change to dark grey or light theme

### Optional Enhancements

- Add project screenshots to the Featured Project section
- Include a resume download link
- Add lab architecture diagrams
- Link to blog posts or write-ups

## Technical Stack

- No frameworks or dependencies
